## 一、数据流重定向与管道

### 1.1 标准流

Linux 系统中每个进程启动时，都会自动打开 3 个标准文件描述符（数据流），这三个数据流是 Linux 进程输入输出的「标准通道」，通过重定向可以灵活控制数据的来源和去向，是 Linux 命令行的核心基础。

| 流名称 | 代码 | 说明 |
| :--- | :--- | :--- |
| 标准输入 (stdin) | 0 | 程序读取数据的来源，默认是键盘 |
| 标准输出 (stdout) | 1 | 程序正常输出的目的地，默认是终端屏幕 |
| 标准错误 (stderr) | 2 | 程序错误或警告信息的输出地，默认也是终端屏幕 |

### 1.2 输出重定向

| 操作符 | 作用 | 示例 |
| :--- | :--- | :--- |
| `>` 或 `1>` | 覆盖写入正确输出 | `echo "hello" > file.txt` |
| `>>` | 追加写入正确输出 | `echo "world" >> file.txt` |
| `2>` | 覆盖写入错误输出 | `ls /notexist 2> error.log` |
| `2>>` | 追加写入错误输出 | `ls /notexist 2>> error.log` |
| `&>` 或 `>&` | 正确 + 错误一起覆盖写入 | `ls /tmp &> all.log` |
| `2>&1` | 将错误输出合并到正确输出流 | `ls /tmp > out.log 2>&1` |
| `/dev/null` | Linux 黑洞，丢弃所有写入的数据 | `ls /tmp > /dev/null 2>&1` |

### 1.3 输入重定向

| 操作符 | 作用 | 示例 |
| :--- | :--- | :--- |
| `<` | 从文件读取输入 | `cat < file.txt` |
| `<< 结束标记` | Here Document，读取多行输入直到标记结束 | `cat > file << EOF` |

![](image2.png)


**非交互式创建文件示例：**

```bash
# 单行写入
echo "hello world" > test.txt

# 多行写入（以 EOF,end,dd 等任意词做结尾标志）
cat > test.txt << EOF
第一行
第二行
第三行
EOF
```
![](image1.png)

汇总一下，是下面的表格

| 命令 | 输出结果 | 说明 |
| :--- | :--- | :--- |
| `echo "hello world"` | hello world | 原样输出字符串 |
| `echo $SHELL` | /bin/bash | `$变量名` 会解析变量值 |
| `echo SHELL` | SHELL | 不加 `$` 原样输出 |
| `a=156; echo $a` | 156 | 自定义变量（等号左右不能有空格） |

### 1.4 管道（`|`）

- 将前一个命令的**标准输出**作为后一个命令的**标准输入**。
- 管道**默认不传递标准错误**，若需传递错误流，需先使用 `2>&1` 合并。

```bash
# 示例：查看所有用户并按 UID 排序
cat /etc/passwd | sort -t: -k3 -n
```

### 1.5 tee 命令（分流器）

从标准输入读取数据，**同时**写入标准输出和指定文件，常用于调试管道中间结果。

```bash
# 将 ls 输出同时写入 screen 和 file.log
ls -l | tee file.log | grep ".txt"
```

### 1.6 后台运行

- 命令末尾加 `&`：将命令放入后台运行（仅适用于非交互式程序）。
- `jobs`：查看当前终端下的后台任务。
- `Ctrl + C`：终止前台进程。

## 二、Vim 编辑器常用操作

我们先把知识点汇总整理一下`ovo`

### 2.1 模式切换

- **命令模式**：默认模式，按 `Esc` 返回。
- **输入模式**：按 `i`, `a`, `o` 等进入。
- **末行模式**：命令模式下按 `:` 进入。

### 2.2 光标跳转

| 快捷键 | 作用 |
| :--- | :--- |
| `gg` | 跳到文件第一行 |
| `G` | 跳到文件最后一行 |
| `^` 或 `0` | 跳到行首 |
| `$` | 跳到行尾 |
| `w` | 跳到下一个单词开头 |
| `b` | 跳到上一个单词开头 |
| `数字gg` 或 `数字G` | 跳转到指定行 |

### 2.3 删除、复制与粘贴

| 快捷键 | 作用 |
| :--- | :--- |
| `dd` | 删除（剪切）当前行 |
| `数字dd` | 删除多行 |
| `d^` / `d$` | 删除到行首 / 行尾 |
| `yy` | 复制当前行 |
| `数字yy` | 复制多行 |
| `p` | 粘贴到下一行 |

### 2.4 进入输入模式

| 快捷键 | 作用 |
| :--- | :--- |
| `i` | 在光标前插入 |
| `I` | 在行首插入 |

| `o` | 在下一行新开一行插入 |
| `O` | 在上一行新开一行插入 |

| `S` | 删除整行并插入 |

### 2.5 末行模式常用命令

**保存与退出**

| 命令 | 作用 |
| :--- | :--- |
| `:q` | 退出（未修改时） |
| `:q!` | 强制退出，不保存 |
| `:w` | 保存 |

**查找与替换**

**其他实用命令**

| 命令 | 作用 |
| :--- | :--- |
| `:r 文件名` | 将指定文件内容读入当前光标处 |
| `:g/关键字/d` | 删除所有包含关键字的行 |

### 3.1 查看命令

| 命令  | 作用 | 常用参数 |
| :---  | :--- | :--- |
| `cat`  | 查看小文件、合并文件 | `-n` 显示行号，`-b` 只给非空行加行号 |

### 3.2 grep 过滤

`grep` 是强大的文本搜索工具，能在文件中查找包含指定字符串的行，可结合管道命令，具体命令为  `grep [选项] "查找内容" 文件名`。

| 选项 | 作用 | 示例 |
| :--- | :--- | :--- |
| `-n` | 显示行号 | `grep -n root /etc/passwd` |
| `-v` | 反向匹配（排除） | `grep -v nologin /etc/passwd` |
| `-i` | 忽略大小写 | `grep -i d /etc/passwd` |
| `-A 数字` | 显示匹配行及后 N 行 | `grep -A2 halt /etc/passwd` |
| `-B 数字` | 显示匹配行及前 N 行 | `grep -B2 sshd /etc/passwd` |
| `-C 数字` | 显示匹配行及前后 N 行 | `grep -C2 ftp /etc/passwd` |
| `-c` | 统计匹配行数 | `grep -c nologin /etc/passwd` |

**正则表达式示例：**

| 表达式 | 含义 | 示例 |
| :--- | :--- | :--- |
| `^root` | 以 root 开头 | `grep "^root" /etc/passwd` |
| `sh$` | 以 sh 结尾 | `grep "sh$" /etc/passwd` |
| `^[0-9]` | 以数字开头 | `grep "^[0-9]" file` |
| `^$` | 空行 | `grep -v "^$" file`（显示非空行） |

### 4.3 find 文件查找

`find` 是强大的实时文件查找工具。

**基本格式：**
```bash
find [路径] [条件] [操作]
```

**常用查找条件：**

| 条件 | 说明 | 示例 |
| :--- | :--- | :--- |
| `-name` | 按文件名（支持通配符） | `find /etc -name "host*"` |
| `-type f/d` | 按类型（文件/目录） | `find / -type f -name "*.conf"` |
| `-size` | 按大小 | `find / -size +100M` |
| `-mtime` | 按修改时间 | `find / -mtime -5`（5天内修改过） |
| `-user` | 按所属用户 | `find /home -user root` |
| `-perm` | 按权限 | `find / -perm 644` |
| `-empty` | 查找空文件/目录 | `find /tmp -empty` |

**逻辑组合：**

- 与：`find / -name "*.txt" -size +1M`
- 或：`find / -name "*.txt" -o -name "*.log"`
- 非：`find / ! -name "*.txt"`

**对查找结果执行操作：**

```bash
# 删除所有 .tmp 文件
find /tmp -name "*.tmp" -exec rm -f {} \;
```
