Docker入门指南

2026.09.05 大三上学期

明天就开始学习 k8s 了，同时，这也意味着 Docker 的讲解结束了。

在这里，我将根据老师上课的课件，用两台 Rocky9 从头地重新做一遍实验并重新整理 Docker 相关的知识点。

本篇为简单一些的内容OvO

一、 搭建 Docker 环境

（1）理解

每次安装新的软件或换成新的系统，正确安装软件，部署环境是第一个难题。在 Rocky Linux 9 中，我们比较省心的部署方法是使用社区的脚本，让它自动完成换源、安装和配置加速。

bash <(curl -sSL https://linuxmirrors.cn/docker.sh)

但为了稍微更详细一点地了解它的原理，我们使用阿里云镜像源安装并启动Docker。

由于一些国际原因（嗯……），我们在国内访问 Docker Hub 官方源是很不顺畅的。这就需要镜像加速器啦。

（2）实验

登录进虚拟机（docker1: 192.168.86.101，docker2: 192.168.86.102），更新系统并安装必要工具。

# 更新系统所有软件包（包括内核），这是避免后续依赖冲突的关键一步[reference:4]
dnf update -y
# 安装 yum-utils（仓库管理工具）和 Docker 依赖的存储驱动[reference:5][reference:6]
dnf install -y yum-utils device-mapper-persistent-data lvm2

添加阿里云仓库并配置镜像加速器。

# 1. 添加阿里云的 Docker CE 仓库
dnf config-manager --add-repo https://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo

# 2. 安装 Doc成功）
dnf install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plu 

# 3. 创建配置文件（如已存在则覆盖）
cat > /etc/docker/daemon.json <<EOF
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://docker.1ms.run",
    "https://registry.docker-cn.com"
  ],
  "dns": ["8.8.8.8", "114.114.114.114"]
}
EOFgin

# 4. 启动 Docker 并设置开机自启
systemctl enable --now docker

# 5. 验证安装
docker run hello-world

我们看到，它已经拉取成功了。

在此，我们提前拉取几个后续实验会用到的镜像（建议有条件的各位，可以科学地上网）。

# 拉取 busybox（轻量调试工具）
docker pull docker.1ms.run/busybox
docker tag docker.1ms.run/busybox busybox:latest

# 拉取 nginx（用于 web 服务）
docker pull docker.1ms.run/nginx
docker tag docker.1ms.run/nginx nginx:latest

# 拉取游戏 2048（可选）
docker pull docker.1ms.run/yakexi007/game2048

二、 Docker 基础操作

（1）理解

这一小节（基础操作）是一些简单命令的集合，只需要 docker1 就可以完成演示，目的是熟悉常用命令。由于课件上的环境为 CentOS7 ，与我现在所用到的环境不同，命令会有轻微的差别（问题不大）。

（2）实验

拉取镜像

我们从 Docker Hub 上拉取 busybox 镜像（若配置了加速器，会走加速后的地址）。这是一个极简的 Linux 工具集，体积小，适合做容器调试。

# docker1
docker pull busybox
查看本地镜像列表

通过docker images，终端会显示出所有已下载的镜像（REPOSITORY、TAG、IMAGE ID、SIZE）。

[root@docker1 ~]# docker images
                                                                                                                                i Info →   U  In Use
IMAGE                                      ID             DISK USAGE   CONTENT SIZE   EXTRA
busybox:latest                             dc2d74b28e4c       6.74MB         2.23MB
docker.1ms.run/busybox:latest              dc2d74b28e4c       6.74MB         2.23MB
docker.1ms.run/nginx:latest                05b8cb60c354        250MB         69.2MB
docker.1ms.run/yakexi007/game2048:latest   8a34fb9cb168       77.2MB         17.8MB
hello-world:latest                         5dd0d3e6e255       21.8kB         9.49kB    U
nginx:latest                               05b8cb60c354        250MB         69.2MB
运行一个一次性容器
[root@docker1 ~]# docker run busybox echo "hello world"
hello world

这里，docker run是指，基于镜像启动容器；busybox是指定的镜像名；echo "hello world"是容器启动后执行的命令。容器运行结束后，主进程结束了，容器也会自动退出。

交互式运行容器
[root@docker1 ~]# docker run -it --name helloworld busybox
/ # ls
bin    dev    etc    home   lib    lib64  proc   root   sys    tmp    usr    var
/ # touch file1
/ # ls
bin    etc    home   lib64  root   tmp    var
dev    file1  lib    proc   sys    usr
/ # exit
[root@docker1 ~]# docker start helloworld
helloworld
[root@docker1 ~]# docker exec -it helloworld /bin/sh
/ #

-it是交互式终端（-i 保持 STDIN 打开，-t 分配伪终端），--name helloworld用以给容器命名（分配命名空间）。输入 exit 退出容器后，容器停止，下次进入这个容器，只需输入docker exec -it helloworld /bin/sh就进去啦（但也可能需要重启一下容器）。

查看容器状态
[root@docker1 ~]# docker ps          # 只显示运行中的容器
CONTAINER ID   IMAGE     COMMAND   CREATED          STATUS         PORTS     NAMES
eaa46c1a7be5   busybox   "sh"      11 minutes ago   Up 2 minutes             helloworld
[root@docker1 ~]# docker ps -a       # 显示所有容器（包括已停止）
CONTAINER ID   IMAGE         COMMAND                CREATED          STATUS                      PORTS     NAMES
eaa46c1a7be5   busybox       "sh"                   11 minutes ago   Up 2 minutes                          helloworld

我们看到helloworld容器正处于 Up 状态。

重新连接（attach）到正在运行的容器
[root@docker1 ~]# docker attach helloworld
/ #

我们可以通过attach，重新进入容器的终端会话，这里按 Ctrl + p 然后按 Ctrl + q 可以分离（detach）终端，让容器继续在后台运行，而不是退出。

很长很长的一段信息啊，包含着容器的所有配置信息（网络、挂载卷、资源限制等），配合 grep 筛选会更合适一些。

查看容器的实施资源占用
docker stats helloworld      # 实时显示CPU、内存等

# 输入进去会跳转到一个实时更新的界面，内容与下面输出相近

docker top helloworld        # 显示容器内的进程列表
删除容器与日志
[root@docker1 ~]# docker rm helloworld           # 删除已停止的容器
helloworld
[root@docker1 ~]# docker rm -f $(docker ps -aq)  #  删除所有容器（清理环境）
1ce5cb550000
9c283bd9df01
ec2782cbbce7
[root@docker1 ~]# docker rmi busybox             # 删除镜像
Untagged: busybox:latest

如果需要被删除的容器还在运行，我们可以在命令中加上-f强制删除，这样实际上，容器会先停止再被删除。docker ps -aq 会列出所有容器的 ID，-f将它们强制删除。
如果镜像被容器使用，是无法被删除的，需要先删除容器。

二、 部署应用堆栈（MySQL + HTTPD）

（1）理解

课件里，老师演示了如何使用 mysql 和 httpd 镜像，构建一个简单的 Web 应用。我们按此操作。

（2）实验

1. 导入或拉取所需镜像（课前已经准备）

我们拉取老师分享的两个 .tar 文件，将它们导入本地镜像。

[root@docker1 ~]# docker load -i mysql.tar
Loaded image: mysql:latest
[root@docker1 ~]# docker load -i httpd.tar
Loaded image: httpd:webapp
2. 给镜像打标签（便于识别）
docker tag yakexi007/httpd:webapp httpd:webapp
docker tag yakexi007/mysql:latest mysql:latest

这里是从官网拉取镜像的同学们，名字比较长，需要改一下名字（让它简单一点），我不用改哒。

3. 启动 MySQL 容器

这条命令比较长，会返回一串长数字。

[root@docker1 ~]# docker run -d -p 3306:3306 -e MYSQL_ROOT_PASSWORD=redhat --name dbserver mysql
e28b1efa2736ce410a6638b6e20ea1c54b2c853c51060e7c51e3c2e500557162

里面有一些参数，我们详细看看。-p 3306:3306：将宿主机的 3306 端口映射到容器的 3306 端口（这样外部可以访问 MySQL）；-e MYSQL_ROOT_PASSWORD=redhat：设置 MySQL root 密码；--name dbserver：容器名。

4. 安装 MySQL 客户端（宿主机上）
dnf install -y mysql

或者使用yum install -y mysql也可以啦，所使用的包名为 mysql 或 mariadb

5. 导入数据库（ os.sql 文件）

老师上传了一个os.sql 文件，我们把它导入数据库中。

[root@docker1 ~]# mysql -h 127.0.0.1 -u root -predhat < os.sql
mysql: [Warning] Using a password on the command line interface can be insecure.

这里用-h 127.0.0.1，因为端口映射到宿主机，相当于访问本机。

6. 启动 Web 容器（连接 MySQL）

这条命令也很长捏。

[root@docker1 ~]# docker run -d -p 80:80 --link dbserver:db --name webserver httpd:webapp
WARNING: Links on the default bridge network are deprecated and will be removed in a future release. Use a custom network instead.
965a771640bd268f40ec2bb09a0a6c21ce5fcd636c76fac9f5b1b9bcb7acdbe6

命令中，--link dbserver:db是将 dbserver 容器别名设为 db，并在 Web 容器的 /etc/hosts 中添加解析，使Web 应用可通过 db 主机名访问 MySQL。-p 80:80是用来映射 Web 服务的 80 端口。

7. 访问测试

在浏览器访问 http://192.168.86.201以及 http://192.168.86.201/cgi-bin/action，发现访问成功啦（好耶）。
